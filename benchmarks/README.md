# Benchmarks

Basic benchmarks of articulated on the real-world text trace from [automerge-perf](https://github.com/automerge/automerge-perf).

More info coming soon

## Commands

`pnpm finish-trace <traceName>`: Given a trace with its `finalText` and `edits` (as a file `src/traces/${traceName}.json`), finish it by adding the `proseMirrorEdits` field.
